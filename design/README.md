- `landing-versions/`: four landing-page versions (2026-10-02). The owner picked **V1 Study view**, which became this site's `index.html`. Published copy: https://claude.ai/artifact/N9gGSMzfVhkWQ9g9q5G3Hu

- `frame/`: the first rough frame of the new landing page (2026-10-08), built from the brief and `brief/patterns.md` on top of the live `klaro.css`. English only for now. Open `frame/index.html` through a local server (see the root README).

- `brief/`: the 2026-10-08 brief for the new direction (a tidy brand, a page per product, research, careers, a live demo) and how to run the work with agents. Its later decisions win over its first pages: the first motto was retired, and the site's mottos are now "We don't make content. We connect yours." (tutors) and "Your tutor's explanation. Not a guess." (students). Its screenshots in `brief/refs/` stay local (gitignored).

Courses, tutors and prices in these files are examples. Leave this folder out when deploying the site.
